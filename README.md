# Controle de Clientes — SóTrickDeRespeito

Aplicativo desenvolvido para auxiliar na **administração e organização do projeto SóTrickDeRespeito**.

## Sobre o projeto

O **Controle de Clientes — SóTrickDeRespeito** foi desenvolvido com o objetivo de facilitar o gerenciamento de clientes, prazos e informações financeiras relacionadas ao projeto.

Entre suas funções estão:

- Cadastro de clientes por código;
- Controle de prazo de 10 dias;
- Separação entre clientes ativos e atrasados;
- Marcação de clientes concluídos;
- Controle dos valores pagos;
- Análise de clientes e vendas;
- Relatórios financeiros;
- Exportação para Excel;
- Backup e restauração dos dados;
- Uso otimizado para dispositivos móveis, especialmente iPhone.
